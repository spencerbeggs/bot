# Module

* [dogfood sandbox](dogfood.md) - A sandbox plugin loaded by pnpm claude and never distributed, into which dogfood cycles build capabilities to exercise plugin-bot.
* [plugin-bot for Claude Code](plugin-bot-claude-code.md) - The Claude Code target of plugin-bot, the plugin-engineer agent plus fourteen skills that guide building agent plugins for both hosts.
* [plugin-bot for Copilot](plugin-bot-copilot.md) - The GitHub Copilot target of plugin-bot, a re-authored port of the Claude Code target tracked by a content-hash ledger.
